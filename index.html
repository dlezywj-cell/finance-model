口径定义（全部率值以「营业总收入」为分母）

  1. 毛利率 =（营业总收入 − 营业成本）÷ 营业总收入
  2. 税金及附加率 = 税金及附加 ÷ 营业总收入；期间费用率 =（销售 + 管理 + 研发 + 财务）÷ 营业总收入，含研发费用
  3. 经营性利润率 = 毛利率 − 期间费用率（默认不扣税金及附加，勾选上方选项后变为毛利率 − 税金及附加率 − 期间费用率）
  4. 非经营性利润率 = 其他收益率 + 投资净收益率 + 公允价值变动净收益率 + 资产减值损失率 + 信用减值损失率 + 资产处置收益率
  5. 营业利润率 = 经营性利润率 + 非经营性利润率
  6. 非经常性利润率 = 营业外收入率 − 营业外支出率
  7. 净利率 = 营业利润率 + 非经常性利润率 − 所得税率；归母净利率 = 净利率 − 少数股东损益率
  8. 「口径差额」= 模型净利率 − 报表净利润率。差额主要来自税金及附加、其他业务成本、利息支出等未进模型的科目；差额为 0 表示模型完全闭合。勾选「税金及附加计入经营成本」可验证差额是否主要由该项解释。
  9. 减值为负值（损失）时以负号计入；缺失数据按 0 计入加总。银行、保险、券商无「营业成本」科目，毛利率与经营性利润率不可比，显示为「—」，不适用科目同样显示「—」。
  10. 跨 2018 年年报比较需注意：新准则下研发费用自 2018 年起在利润表单列，此前计入管理费用。因此 2017 年及更早的「研发费用率」为 0、「管理费用率」已包含研发支出，两段口径不可直接对比。
