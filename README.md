# 财务分析模型

输入股票代码与年份区间，一键生成利润表科目重建表。

**在线地址**：https://dlezywj-cell.github.io/finance-model/

## 功能

- 输入 6 位 A 股代码（支持 600519、000001、300750 等），可选输入名称联想
- 选择起始 / 结束年份，按年报或全部报告期提取
- 自动重建利润表：经营性利润 → 营业利润 → 净利润 → 归母净利润
- 每行标注占比、每一列一个报告期，支持最多 30 年跨度
- 导出 CSV / 一键复制到 Excel（可直接粘贴进 Excel 保持分列）
- 支持 URL 参数分享：`?code=600519&from=2020&to=2025&rtype=ALL`

## 指标定义（分母统一为「营业总收入」）

| 分组 | 指标 | 公式 |
| --- | --- | --- |
| 规模 | 收入 YoY | 营业收入同比增长率 |
| 经营性 | 毛利率 | （营业总收入 − 营业成本）÷ 营业总收入 |
| 经营性 | 税金及附加率 | 税金及附加 ÷ 营业总收入 |
| 经营性 | 销售 / 管理 / 研发 / 财务费用率 | 各项费用 ÷ 营业总收入 |
| 经营性 | 期间费用率 | （销售 + 管理 + 研发 + 财务）÷ 营业总收入 |
| 经营性 | 经营性利润率 | 毛利率 − 期间费用率 |
| 非经营性 | 其他收益 / 投资净收益 / 公允价值变动 / 资产减值损失 / 信用减值损失 / 资产处置收益率 | 各项 ÷ 营业总收入 |
| 非经营性 | 非经营性利润率 | 上述六项加总 |
| 合计 | 营业利润率 | 经营性利润率 + 非经营性利润率 |
| 非经常性 | 营业外收入率 / 营业外支出率 | 各项 ÷ 营业总收入 |
| 非经常性 | 非经常性利润率 | 营业外收入率 − 营业外支出率 |
| 净利 | 所得税率 | 所得税费用 ÷ 营业总收入 |
| 净利 | 净利率 | 营业利润率 + 非经常性利润率 − 所得税率 |
| 净利 | 归母净利率 | 净利率 − 少数股东损益率 |

## 口径说明

1. **税金及附加默认不计入经营性利润率**，这是按需求方给定定义实现的口径。页面提供开关「税金及附加计入经营成本」，勾选后经营性利润率 = 毛利率 − 税金及附加率 − 期间费用率。
2. **「口径差额」**行 = 模型净利率 − 报表净利润率。差额主要来自税金及附加、其他业务成本、利息支出等未进模型的科目。制造业该差额通常正好等于税金及附加率，勾选上述开关后差额归零，可据此判断模型是否闭合。
3. **2018 年研发费用口径断裂**：研发费用自 2018 年起在利润表单列，此前计入管理费用。因此 2017 年及更早的研发费用率为 0、管理费用率已包含研发支出，跨 2018 年比较不可直接对比。
4. **金融类企业**（银行、保险、券商）无「营业成本」科目，毛利率与经营性利润率不可比，显示为「—」；不适用的费用科目同样显示「—」。
5. 减值为负值（损失）时以负号计入；通用企业缺失科目按 0 计入加总。

## 数据源

东方财富 F10 利润表接口（`RPT_F10_FINANCE_GINCOME`），JSONP 方式直接取数，无需后端与 API Key。

- 一次请求拉取该标的全部历史报告期（pageSize=500）
- 数据为报表原始值，未做任何平滑、调整或估算
- 数据实时取自东财，若接口变更可能导致页面失效

## 本地运行

纯静态单文件，直接打开 `index.html` 即可。因为走 JSONP，本地 `file://` 也能取数；如遇限制可起本地服务：

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```

## 免责

数据仅供研究参考，不构成投资建议。所有比率均为「÷ 营业总收入」的重建口径，与券商研报口径可能存在差异，使用前请与原始报表核对。
