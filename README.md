# 财务分析模型

输入股票代码与年份区间，一键生成利润表科目重建表。

**在线地址**：https://dlezywj-cell.github.io/finance-model/

## 功能

- **输入代码或名称**：6 位代码（600519 / 000001 / 300750 / 688981 / 920982）、公司名称（宁德时代、寒武纪）、拼音首字母（gzmt）都可以，名称唯一时直接提取，重名时出候选列表点选
  - 覆盖 A 股全部板块：沪市主板、深市主板、创业板、科创板（688）、北交所（920 / 8 开头）
  - 港股暂不支持（如「晶泰控股」会提示只匹配到港股，需改用 A 股标的）
- **9 种报告期口径**：
  - 累计口径：仅年报、全部报告期、一季报、半年报、三季报
  - 单季口径：**全部单季（逐季列出）**、Q2（半年报−一季报）、Q3（三季报−半年报）、Q4（年报−三季报）
  - 「全部单季」把区间内每个季度都摊开成一列（2023Q1、2023Q2…2025Q4），四个季度相加等于该年年报数
- **双标的对比**：第二个输入框填另一只股票（可选），点开任意科目即可把两只画在同一张图上——金额科目并排柱、比率科目双折线；页头可「⇄ 切换主副」把另一只提到表格里看，配色固定（主标的蓝、对比标的橙），切换不会跳色
- **点击任意科目名查看趋势图**：金额类科目（营业总收入）画柱状图，比率类科目画折线图，随所选区间与报告期口径联动；再点一次收起
- 自动重建利润表：经营性利润 → 营业利润 → 净利润 → 归母净利润
- 每行标注占比、每一列一个报告期，支持最长 30 年跨度
- 页头显示该标的**当前已披露到哪一期**（如「数据已更新至 2026三季报」），披露节奏按个股实际数据判断，不做任何补值
- 导出 CSV / 一键复制到 Excel（可直接粘贴进 Excel 保持分列）
- 支持 URL 参数分享：`?code=300750&code2=300014&from=2022&to=2026&rtype=Q3`

## 指标定义（分母统一为「营业总收入」）

| 分组 | 指标 | 公式 |
| --- | --- | --- |
| 规模 | 营业总收入 | 利润表「营业总收入」绝对额（亿元） |
| 规模 | 收入 YoY | 营业总收入同比增长率 |
| 规模 | 归母净利润 | 利润表「归属于母公司股东的净利润」绝对额（亿元） |
| 规模 | 归母净利润 YoY | 归母净利润同比增长率 |
| 经营性 | 毛利率 | （营业总收入 − 营业成本）÷ 营业总收入 |
| 经营性 | 税金及附加率 | 税金及附加 ÷ 营业总收入 |
| 经营性 | 销售 / 管理 / 研发 / 财务费用率 | 各项费用 ÷ 营业总收入 |
| 经营性 | 期间费用率 | （销售 + 管理 + 研发 + 财务）÷ 营业总收入 |
| 经营性 | 经营性利润率 | 毛利率 − 期间费用率 |
| 非经营性 | 其他收益 / 投资净收益 / 公允价值变动 / 资产减值损失 / 信用减值损失 / 资产处置收益率 | 各项 ÷ 营业总收入 |
| 非经营性 | 非经营性利润率 | 上述六项加总 |
| 合计 | 营业利润率 | 经营性利润率 + 非经营性利润率 |
| 非经常性 | 营业外收入率 / 营业外支出率 | 各项 ÷ 营业总收入 |
| 非经常性 | 非经常性利润率 | 营业外收入率 − 营业外支出率 |
| 净利 | 所得税率 | 所得税费用 ÷ 营业总收入 |
| 净利 | 净利率 | 营业利润率 + 非经常性利润率 − 所得税率 |
| 净利 | 归母净利率 | 净利率 − 少数股东损益率 |

## 口径说明

1. **税金及附加默认不计入经营性利润率**，这是按需求方给定定义实现的口径。页面提供开关「税金及附加计入经营成本」，勾选后经营性利润率 = 毛利率 − 税金及附加率 − 期间费用率。
2. **单季口径**：单季金额 = 本期累计 − 同期上一报告期累计（Q2=中报−一季报、Q3=三季报−中报、Q4=年报−三季报），所有比率用单季金额重新计算，收入 YoY 与归母净利润 YoY 同步换成单季同比（由单季金额自算）。「全部单季」用同一套拆分逻辑，只是把 Q1–Q4 全部列出，不单独筛选季度。2002 年以前多数公司只披露年报与中报，早期单季无法拆分时该期会从表中略去，不会用 0 填充。
3. **同比算法**：YoY =(本期 − 上年同期)÷ |上年同期|。上年同期为负（亏损）时仍能给出方向正确的百分比——正数代表减亏或扭亏、负数代表增亏，与东方财富接口口径一致（例：上年亏 4.52 亿、本期盈 20.59 亿 → +555.24%）。上年同期为 0 或无数据时显示「—」。
4. **「口径差额」**行 = 模型净利率 − 报表净利润率。差额主要来自税金及附加、其他业务成本、利息支出等未进模型的科目。制造业该差额通常正好等于税金及附加率，勾选上述开关后差额归零，可据此判断模型是否闭合。
5. **2018 年研发费用口径断裂**：研发费用自 2018 年起在利润表单列，此前计入管理费用。因此 2017 年及更早的研发费用率为 0、管理费用率已包含研发支出，跨 2018 年比较不可直接对比。
6. **金融类企业**（银行、保险、券商）无「营业成本」科目，毛利率与经营性利润率不可比，显示为「—」；不适用的费用科目同样显示「—」。
7. 减值为负值（损失）时以负号计入；通用企业缺失科目按 0 计入加总。

## 数据源

东方财富 F10 利润表接口（`RPT_F10_FINANCE_GINCOME`），JSONP 方式直接取数，无需后端与 API Key。

- 一次请求拉取该标的全部历史报告期（pageSize=500），每次打开都实时请求，不做任何本地缓存
- 数据为报表原始值，未做任何平滑、调整或估算
- 披露节奏因股而异：同一时点有的公司已出三季报、有的还停在中报，页面按各股接口实际返回的最新报告期展示
- 名称搜索走东财 suggest 接口（JSONP，回调参数名为 `cb`）
- 数据实时取自东财，若接口变更可能导致页面失效

## 本地运行

纯静态单文件，直接打开 `index.html` 即可。因为走 JSONP，本地 `file://` 也能取数；如遇限制可起本地服务：

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```
